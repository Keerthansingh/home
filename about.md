## I break things so companies don't have to find out the hard way

Hi, I'm Keerthan — a penetration tester who approaches every security engagement with an attacker's mindset. I learned that most breaches don't come from zero-days. They come from the boring stuff: a reused password, a misconfigured endpoint, an IDOR nobody bothered to check. Finding that boring stuff before someone with worse intentions does — that's the job.

Professionally, I’ve tracked down 50+ vulnerabilities (including 15 critical and 20 high-severity flaws) across 20+ web applications and 15+ APIs in active client engagements. Right now, I'm pursuing my MSc in Cyber Security at the University of Hertfordshire, while continuously hunting on HackerOne and Bugcrowd. 

Outside of client work, I like to build my own vulnerable machines from scratch (deliberately broken SSH, FTP, MySQL, Apache — the works) just to have a sandbox nobody else has already solved. I also trained a Random Forest classifier to detect malware hiding in IoT firmware, hit a 92% accuracy rate, and got it published in a peer-reviewed international journal — because sometimes the most interesting problems live outside the OWASP Top 10.   

This blog is where the CTF machines live. Not polished tutorials — actual notes from actual attempts, including the wrong turns.

### The credentials, if you need them
CEH v12 · eJPT v2 · CRTA (Red Team) · CNSP · API Penetration Tester

### What I'm actually good at
Manual web and API security, secure code review (Java/Python via Veracode, Coverity, CodeQL), Active Directory attacks, and turning a five-line nmap scan into a full compromise chain.

### Tools of choice
Burp Suite, Nmap, Metasploit, Wireshark, SQLmap, Postman — plus whatever the box forces me to learn on the spot.
